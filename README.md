# CampusConnect – Campus Event Management Portal

## About the Project

CampusConnect is a web-based Campus Event Management Portal designed to make it easier for students to discover and participate in college events.

The platform provides a simple interface where students can view upcoming events and register for them online. It also aims to help administrators manage campus events efficiently.

## Features

- View upcoming college events.
- Browse event information.
- Register for events online.
- Simple and user-friendly interface.
- Responsive website layout.
- Event registration functionality.

## Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Interactive functionality and event registration.

## Getting Started

Follow these steps to run the project locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the CampusConnect portal.
